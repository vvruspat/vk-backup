# VK Backup

Десктопное приложение на Tauri 2, React, TypeScript и Radix UI. Сохраняет доступные данные ВК непосредственно на компьютер пользователя. Музыка не включена.

## Возможности

- Фотоальбомы, включая системные, с выбором целого альбома или отдельных фотографий на всех страницах.
- Видео и видеоальбомы; документы в исходном формате.
- Личный аккаунт и сообщества, где пользователь администратор (`groups.get`, `filter=admin`). Можно выбрать несколько источников в одной очереди. У сообществ используется отрицательный `owner_id`.
- Профиль, сведения о сообществе, стена, список друзей и доступная переписка в JSON. Переписка экспортируется с полной пагинацией истории каждого доступного диалога.
- Выбор папки системным диалогом, общий прогресс и прогресс текущего файла, скорость, пауза, продолжение, отмена, отчёт о пропусках.
- Повторные запуски: размер и SHA-256 каждого готового файла проверяются; целые файлы пропускаются, повреждённые скачиваются заново. JSON обновляется. Незавершённый текущий файл при новом запуске скачивается заново.
- Предварительная запись владения файлом в manifest позволяет восстановиться после закрытия процесса между сохранением файла и записью результата. Блокировка папки не позволяет двум экземплярам писать один архив одновременно.
- `index.html` — локальная галерея без внешних запросов; файлы и описания по альбомам, `manifest.json` с результатами и предупреждениями.

## Запуск и сборка

Нужны Node.js 22.12+ (или 24+), актуальный стабильный Rust и [системные зависимости Tauri](https://v2.tauri.app/start/prerequisites/). Проект проверен с Rust 1.99.

```sh
npm ci
npm run tauri dev
```

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --locked
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets --locked -- -D warnings
npm run tauri build
```

Установщики появляются в `src-tauri/target/release/bundle`. На macOS можно собрать только приложение: `npm run tauri build -- --bundles app`.

Если глобальная установка Rust принадлежит администратору, можно создать локальную установку в игнорируемой папке `.toolchain`. Обёртка `npm run tauri` обнаруживает её автоматически:

```sh
RUSTUP_HOME="$PWD/.toolchain" rustup toolchain install stable --profile minimal
RUSTUP_HOME="$PWD/.toolchain" rustup component add rustfmt clippy
RUSTUP_HOME="$PWD/.toolchain" cargo test --manifest-path src-tauri/Cargo.toml --locked
```

В `.github/workflows/desktop.yml` настроены проверки и сборки для macOS, Windows и Linux. Эти сборки становятся артефактами CI, а не публичными релизами. Windows и Linux требуют проверки на соответствующих платформах; локально проверена macOS Apple Silicon. Приложение для macOS пока без подписи разработчика и нотариализации.

## Подключение ВК

Для первого реального входа нужен публичный ID собственного приложения ВК или существующий **пользовательский токен VK API**. Встроенного чужого ID, сервисного ключа и токена в исходниках нет.

1. Откройте «Подключить ВК».
2. Для браузерного входа введите ID приложения и настройте в его кабинете точный адрес возврата: `http://127.0.0.1:47851/callback`.
3. Выберите VK ID (OAuth 2.1, PKCE, случайный state) или существующее Standalone-приложение VK API. Последнее использует старый implicit flow и доступно только если ВК и настройки вашего приложения разрешают его и адрес возврата.
4. Если настройка локального redirect или выдача прав на медиа недоступны, на вкладке «У меня есть токен» вставьте токен пользователя или полную ссылку после авторизации, содержащую `access_token`.

Для основного сценария нужны права `photos video docs groups`. Дополнительные разделы требуют прав `wall friends`, переписка — `messages`, если ВК разрешает их вашему типу приложения. Список запрашиваемых прав можно изменить до входа. Наличие VK ID авторизации само по себе не подтверждает доступ к методам медиа VK API. Каждый раздел проверяется отдельно; отказ отображается в интерфейсе.

Для заранее настроенного публичного ID можно скопировать `.env.example` в `.env.local` и заполнить `VITE_VK_CLIENT_ID`. **Не помещайте токены или секреты в VITE-переменные:** они включаются в интерфейс при сборке.

Токен не хранится в localStorage, файлах или настройках. Он находится в памяти Rust до выхода/закрытия приложения. Вход VK ID обновляется refresh-токеном во время текущей сессии. Пароль вводится непосредственно на сайте ВК в системном браузере. Локальный обработчик слушает только `127.0.0.1`, проверяет state и прекращает ожидание через 5 минут.

## Видео

Сначала выбирается наибольший доступный `mp4_*` из VK API. Если прямого файла нет, выполняется дополнительный запрос `video.get` с идентификатором записи и её ключом доступа. При включённой настройке «Видео через yt-dlp» используется установленный на компьютере [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation). Приложение не устанавливает его автоматически.

yt-dlp должен быть доступен в PATH; на macOS также проверяются `/opt/homebrew/bin/yt-dlp` и `/usr/local/bin/yt-dlp`. Используется лучший готовый MP4 с видео и звуком (`best[ext=mp4]`), поэтому отдельный ffmpeg не нужен; это может быть ниже максимального качества, доступного только отдельными дорожками. При паузе процесс прекращается и после продолжения возобновляет временную загрузку.

Видеозаписи, требующие дополнительной браузерной сессии, DRM, неподдерживаемого формата или прав, могут остаться недоступными. Cookies браузера автоматически не извлекаются. Такие записи не считаются сохранёнными и включаются в отчёт.

## Структура архива

```text
VK Backup - id123/
  Мой аккаунт/id123/
    Фото/Название альбома [123_photos_456]/
      album.json
      Название [123_789].jpg
      Название [123_789].metadata.json
    Видео/...
    Документы/...
    Данные/...
  Сообщества/club456/
    Фото/...
    Видео/...
    Документы/...
    Данные/...
  index.html
  manifest.json
  .backup.lock
```

Имена совместимы с Windows, macOS и Linux. Файлы сначала записываются во временный `.part`, после полного получения перемещаются на место. Ошибка HTTP, HTML вместо файла, оборванное соединение и неполная длина не дают отметить файл готовым. Внутри архива запрещены символические ссылки и выход за пределы выбранной папки. Токены, ключи доступа и подписанные ссылки на видеоплеер удаляются из экспортированных метаданных.

## Границы бэкапа

Это экспорт доступных приложению данных, а не гарантированная копия всего внутреннего хранилища ВК. Архив не включает музыку, удалённые данные, Stories, комментарии и обсуждения, участников сообществ или недоступные приватные записи. Вложения стены и переписки сохраняются **как метаданные в JSON**, их бинарные файлы автоматически не обходятся. Для медиа выбирайте фотоальбомы, видео и документы.

Вход через VK ID/Standalone, действительные права на медиа, реальные приватные видео и выгрузка конкретного аккаунта требуют проверки с пользовательским токеном и настройками приложения. Локальные тесты используют изолированный сервер и демонстрационные данные и не подтверждают эти живые границы.

## Демонстрация интерфейса

```sh
npm run dev
```

Откройте `http://localhost:1420/?demo=1`. Это явно помеченная симуляция: SVG-иллюстрации, демонстрационный аккаунт и сообщества. Файлы не скачиваются. Обычный веб-предпросмотр и десктопная сборка не подменяют данные ВК демонстрацией.

## Источники интеграции

- [Официальная схема VK API 5.199](https://github.com/VKCOM/vk-api-schema): параметры фотоальбомов, видео, документов и сообществ.
- [Официальный VK ID SDK](https://github.com/VKCOM/vkid-web-sdk/blob/master/src/auth/auth.ts): PKCE, state, device_id, обмен кода и обновление токена.
- [Tauri 2](https://v2.tauri.app/): нативные команды, системные диалоги, события и ограничения возможностей окна.

В этом рабочем каталоге изначально не было Git и origin. Создана локальная ветка main; удалённый репозиторий не создавался.
